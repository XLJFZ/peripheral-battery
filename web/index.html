为什么可能与官方软件显示不同？

本地连接器优先读取正在运行的雷云日志：按设备序列号精确匹配，记录不超过 120 秒且状态有效时直接使用雷云百分比。日志过期、状态不可用或无法匹配时回退到 HID 直读，原始值按 0–255 换算并四舍五入显示。纯网页模式仍使用 WebHID。官方软件的刷新时间和处理方式可能不同；这不是已经查明的误差原因。可在设备卡片中查看采样时间和原始读数，再保存记录核对。这里不会用固定偏移值强行对齐官方百分比。

每分钟自动读取，手动刷新会向新版本地连接器请求重新采样。读取失败或超过 90 秒未更新时会清除百分比。Mac 菜单栏版目前另有源码预览包，尚未经过 Mac 实测。

两种连接方式

本地连接器支持已适配的雷蛇和迈从设备，以及 Windows 提供电量的外设。纯网页模式使用 WebHID，需要 Chrome / Edge 和你的设备授权。

设备未出现？

请先唤醒设备。浏览器可能禁止访问鼠标接口，此时请双击交付包中的“启动网页版”。其他品牌的 2.4G 设备需要单独适配电量协议。
