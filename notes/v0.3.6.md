# v0.3.6 · 安装版

本版主要补上 Windows 安装包，功能与 v0.3.5 一致。

## 两种安装形态

| | 安装版（新增） | 便携版 |
| --- | --- | --- |
| 文件 | `Peripheral-Battery-Setup-0.3.6.exe`（约 78 MB） | `Peripheral-Battery-0.3.6-x64.exe`（约 78 MB） |
| 安装位置 | `%LOCALAPPDATA%\Programs\PeripheralBattery` | 任意位置，单个文件 |
| 权限 | 普通用户即可，不需要管理员 | 不需要 |
| 开始菜单 / 桌面快捷方式 | 有（桌面可选） | 无 |
| 卸载 | 设置 → 应用，或开始菜单里的卸载 | 删除文件 |
| 设置位置 | 相同：`%APPDATA%\PeripheralBatteryNative` | 相同 |

两种形态共用同一份程序与设置，可以互相切换：安装版会替换掉便携版的启动入口，卸载时按需保留设置。

第三种「目录版」（含 Python HID 后端）不随 Release 提供二进制：执行 `build-native.ps1` 自行构建，体积约 236 MB。三者关系：安装版与便携版功能相同，目录版多出其他品牌的 HID 后端覆盖。

## 安装包做了什么

- 单文件安装向导（Inno Setup），简体中文界面，可切换英文。
- 安装到当前用户目录，默认不请求管理员权限；如需为所有用户安装，向导里会提示提权。
- 开始菜单快捷方式必选，桌面快捷方式可选；「开机自动启动」默认勾选，写入 `HKCU\...\Run`（`--minimized`）。
- 安装前若程序正在运行，安装器会请求关闭（基于应用互斥量），避免文件占用。
- 卸载时结束进程、删除自启项；会询问是否同时删除 `%APPDATA%\PeripheralBatteryNative` 中的设置，默认保留。

## 验证

- 安装包在干净目录安装成功，开始菜单 / 桌面快捷方式可用，程序启动并读到雷蛇 75% 电量。
- 卸载后程序目录、自启项清理干净；选择保留设置时 `settings.json` 仍在。
- 静默安装（`/VERYSILENT`）与静默卸载（`/VERYSILENT`）均能完成，退出码 0。

## 已知限制

- 安装包未做代码签名，首次运行可能触发 SmartScreen「更多信息 → 仍要运行」。
- 无自动更新，新版本仍需下载安装包覆盖安装（设置会保留）。
