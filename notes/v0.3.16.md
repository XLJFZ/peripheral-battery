# v0.3.16 · 设备管理 + 通知跃迁

2026-11-03。基于同类项目（HaloBattery / ozBluetoothLEBatteryMonitor）功能调研新增两组功能。

## 设备管理

- **重命名设备**：浮窗设备卡右键 → 重命名设备。自定义名称全局生效（浮窗、托盘提示、通知），重启后保留；清空并保存即恢复系统原始名称。
- **隐藏设备**：浮窗设备卡右键 → 隐藏此设备。隐藏后不出现在浮窗、托盘图标与通知中；可在 设置 → 设备 → 已隐藏的设备 中恢复显示。
- **隐藏无法读取电量的设备**：新增全局开关，读不到任何电量（主电量与 TWS 分电量均无）的设备不再显示。

## 低电量通知：冷却时间 → 状态跃迁

通知不再按 30 分钟冷却重复弹出，改为跟踪每台设备的电量档位（正常 / 低 / 危急，按有效阈值判定）：

- 只有**档位跌落**时通知一次（正常→低、低→危急；电量快速跌到危急只通知危急一次）。
- 电量停在低位期间不再重复打扰。
- 充电、断开或暂时读不到电量会**重新武装**：再次跌落会再次通知。
- Toast 发送失败会在下次观察时重试（旧实现先记冷却再发送，失败也白等 30 分钟）。
- 应用启动时已处于低电位的设备提醒一次。

## 设置页

新增「设备」折叠组：隐藏未知电量设备开关 + 已隐藏设备列表（可逐个恢复显示）。
