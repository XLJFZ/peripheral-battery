# v0.3.12 · 设置窗口底栏收紧

设置窗口加了「不保存并关闭」后底栏变成四个按钮，540px 窗口装不下——中文下「GitHub 仓库」被左边缘截断，英法德语更宽。

## 改动

- 底栏按钮间距 12→8px，内边距 16,8/20,8 → 10,7/12,7。
- 各语言底栏文案统一缩短（按钮语义不变，游戏回报率对话框标题同步变短）：
  - 回报率：游戏回报率调度→回报率调度 / Game polling rate→Polling rate / Fréquence en jeu / Sondeo en juego / Polling in gioco
  - 仓库：GitHub repository→GitHub repo / GitHub-Repository→GitHub-Repo / Repositorio de GitHub→Repo GitHub 等
  - 保存/放弃：Save & Close→Save、Close without saving→Discard / Kaydet ve Kapat→Kaydet / Guardar y cerrar→Guardar 等
- 中文界面四个按钮总宽约 430px（原约 500px 截断），最长语言（德语）也留有余量。

无逻辑改动，纯文案与布局参数。
