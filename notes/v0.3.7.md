# v0.3.7 · 三语界面补全

设置窗口、游戏回报率调度窗口、托盘取色窗口此前有 24 处文案写死在 XAML/代码里，切到英文或土耳其语时会中英混排。本版把这些文案全部收进本地化词表。

## 补全范围

| 位置 | 处理 |
| --- | --- |
| 设置页「托盘图标与颜色」整段 | 标题、说明、色阶图例、四个颜色标签、格式提示、显示方式、圆环粗细 |
| 设置页「界面外观」「面板大小」 | 标题与说明 |
| 设置页复选框「按电量自动变色」 | `Content` 属性此前漏掉 |
| 设置页与「关于」窗口的「GitHub 仓库」「游戏回报率调度」按钮 | 改为词条 |
| 游戏回报率调度窗口 | 窗口标题、已验证说明、开关、两项频率标签、进程名提示、保存按钮 |
| 托盘取色窗口 | 窗口标题、标题文字、应用按钮 |
| 阈值 / 刷新间隔下拉 | 原来中文界面显示英文选项；改为词条，阈值统一 `10%`~`40%`＋「默认（全局）」 |
| 托盘图标样式下拉 | 存储值保持 `圆环 / 数字 / 圆环 + 数字` 不变（兼容旧配置），显示文本走 `TrayStyleOption` 映射本地化 |

新增 27 个词条，中 / 英 / 土三语齐全。

## 实现要点

- XAML 用 `{DynamicResource}`，`LocalizationService.ApplyLanguage` 会同步写入 `Application.Resources`，切换语言即时生效。
- 代码构建的两个窗口（`GamePollingWindow`、`TrayColorWindow`）用 `LocalizationService.GetString`，在窗口创建时求值。
- 托盘样式下拉改成 `SelectedValuePath="Value"` + `DisplayMemberPath="Display"`，避免把显示文案写进 `settings.json` 破坏旧配置。
- 静态列表（阈值、刷新间隔、托盘样式）在窗口构造时求值，切换语言后重开设置页即可看到新文案 —— 与设置页本身的刷新方式一致。
