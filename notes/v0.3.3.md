# v0.3.3 · 普通版默认、单层圆角与单文件便携版

## 1. 默认外观改回普通版

设置页仍然只有两个选项，但顺序与默认值改为 **普通版（默认）** / 液态玻璃。

v0.3.0 / v0.3.1 的旧配置（`System` / `Dark` / `Light` / `液态玻璃` / `液态玻璃（低透明）`）在升级后会统一归一化为普通版。判断依据是 `settings.json` 中新增的 `ThemeVersion` 字段：v0.3.3 之前写出的文件没有该字段，读取时按版本 0 处理并执行一次归一化；只有在 v0.3.3 设置页里显式保存过外观选择，才会保留液态玻璃。

## 2. 液态玻璃跟随系统深色设置

旧版本把液态玻璃强制映射到浅色（`isDark = false`），因此在深色桌面上会出现"浅色玻璃 + 深色桌面"的割裂感。现在液态玻璃读取 `AppsUseLightTheme`，深色系统使用深色玻璃配色（深灰半透明面板、白色高光描边、白色文字），浅色系统使用原来的浅色配色。系统切换主题时会立即重算，不需要重启。

悬停高亮此前固定为白色（ARGB 95,255,255,255），深色玻璃下会闪白；现在改用主题资源 `PeripheralCardHoverBrush`，深色下是白色微亮、浅色下是轻微压暗。

## 3. 修复两层圆角

原因：飞行面板的 `Border` 带 `Margin="6"` 和 22px 圆角，窗口本身又被 DWM 以约 8px 圆角裁切，Acrylic 背景铺满整个窗口矩形，于是外面一层系统圆角、里面一层 22px 圆角同时可见；`DropShadowEffect` 也因为 6px 边距可容纳而被画在窗口内，进一步强化了双层感。

修复：面板改用与窗口一致的 8px 圆角、`Margin="0"`，移除额外的 6px 内缩与投影（窗口阴影由 DWM 提供），页脚底角同步为 7px。现在只保留一条圆角边缘。

## 4. 单文件便携版

新增 `build-portable.ps1`：以 `PublishSingleFile` + `IncludeNativeLibrariesForSelfExtract` + 压缩方式发布自包含 EXE，体积约 100 MB，双击即可运行，不需要安装 .NET、不需要解压、不需要同目录 DLL。

- 雷蛇设备目录 `razer_devices.json` 改为同时内嵌到程序集，单文件下仍可读取（外部文件存在时优先用外部文件）。
- `--ui-smoke` 冒烟检查兼容单文件：程序集 `Location` 为空时不再要求磁盘存在 `Accessibility.dll`，报告中标记 `singleFile: true`。
- 新增 `tools/check_portable_exe.py`：把 EXE 单独复制到空目录后运行冒烟检查，验证菜单、提示框、游戏调度窗口都能从包内加载。

已知限制：单文件版不包含 Python HID 后端（`UniversalBatteryTray.exe`），因此"其他品牌 HID"一列会显示后端缺失；雷蛇原生电量、蓝牙 GATT/PnP、手柄与耳机读取不受影响。需要完整后端时使用目录版 ZIP。

## 5. 验证

- `dotnet test`（全量 300 项）通过；新增 13 项外观断言覆盖旧配置归一化、显式选择保留、空值与未知值回落。
- `--glass-preview` 现在渲染 4 个变体（普通版/液态玻璃 × 深色/浅色），并对活动配色做断言，浅色面板上的设备卡片改为轻微压暗以保证可分辨。
- 单文件 EXE 在空目录中通过 `--ui-smoke`（菜单、提示框、游戏调度窗口）。
- 真机截图确认：深色系统下液态玻璃为深色面板、白色文字、单一圆角边缘；普通版仍为原深色界面。

Windows 10（build < 22000）没有 Acrylic 与窗口圆角，液态玻璃会回退为不透明表面，避免出现方形毛玻璃。
