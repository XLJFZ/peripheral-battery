# v0.3.13 · 更新链路加固与设置页修复

2026-11-03。代码 review（第十一轮）发现的全部 P3 问题与此前遗留的更新链路 P2 项，一次性收口。

## 更新链路（P2）

- **安装目录走注册表**：安装器现在把实际安装目录写入 `HKCU\Software\PeripheralBattery\InstallDir`，应用内更新据此识别安装副本——此前路径写死为 `%LOCALAPPDATA%\Programs\PeripheralBattery`，选择「为所有用户安装」（Program Files）的场景永远只能跳转下载页。v0.3.13 之前安装的副本无此注册表值，自动回落到旧路径，行为不变。
- **HttpClient 复用**：更新检查与安装包下载改用共享客户端，不再每次 new + 释放（避免 socket 反复建连）。
- **GitHub API 节流**：检查结果进程内缓存 60 秒，反复点击「检查更新」不再空烧未认证 API 的 60 次/小时配额；HTTP 403/429 现在明确报「触发限流，请稍后再试」，不再与普通网络失败混为一谈。
- **日志轮转**：`update.log` 超过 1 MiB 轮转为 `.old`（保留一代）；静默升级启动安装器前也会先轮转 `install.log`，不再无限增长。

## 设置页（P3）

- **切换语言后下拉立即换文案**：界面语言、托盘样式、主题、面板大小、阈值、刷新间隔、自动隐藏等下拉此前在绑定时就固定了当时语言的显示串，切语言后保持旧文案直到重开窗口；现在保存后即时刷新。
- **底栏宽度有 CI 断言**：新增 `--settings-probe` 布局探针 + `tools/check_settings_footer.py`，对全部 8 种语言测量底栏四个按钮的期望宽度，超宽即构建失败——德语溢出问题从「手调防回归」变为「机器把关」。

## 其他

- 浮窗每次打开不再整读一遍 `settings.json`（UI 线程磁盘 IO），改为按文件时间戳缓存，设置变化时仍即时生效。
