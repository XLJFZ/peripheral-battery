# v0.3.19 · 三外观正式发布版

2026-11-04。把「普通版 / 毛玻璃 / 液态玻璃」三种界面外观作为独立可下载版本正式发布；含聚合图标充电呼吸与主题切换崩溃修复。

> 说明：v0.3.18 的 release 资产仍为三外观改动前的构建产物（tag 停在呼吸动画轮）。本版改为 v0.3.19 独立 tag 发布，已装 v0.3.18 的用户走应用内更新即可收到三外观。

## 三种界面外观

- 新增「毛玻璃」外观，设置 → 外观下拉现为三项：**普通版（默认）/ 毛玻璃 / 液态玻璃**。
- 毛玻璃与液态玻璃均跟随 Windows 深色/浅色设置；毛玻璃使用更高遮盖与边缘高光，可读性优先；液态玻璃中心更透明、边缘呈透镜状高光。
- 液态玻璃面板圆角统一为 8，与窗口系统圆角和底部工具栏圆角匹配，消除双圆角/错位。
- 电量百分比数字始终与进度条同色（正常绿、低电量橙），不再因玻璃模式强制变黑。
- 8 种语言新增「毛玻璃」本地化；`--glass-preview` 渲染 6 变体（3 主题×深浅）并断言三版切换。
- 旧配置迁移：v0.3.3 之前文件归一化为普通版；v0.3.3 起的显式选择保留，毛玻璃为新增合法值。

## 聚合图标充电呼吸

- 任一可见设备充电时，该设备的电量环变绿并呼吸（约 1.3 秒正弦周期，透明度 45%↔100%），呼吸中的环不再叠加角标圆点——环本身即充电信号。非充电设备的环不受影响，保持原三档配色。
- 单设备 / 数字样式同样生效（单环呼吸，数字保持档位色）。
- 复用现有「充电时电量环呼吸动画」开关；关闭后回退为原来的角标标记。
- 脉动定时器触发条件放宽：任一可见设备充电即启动（此前只看最低电量设备是否充电）。

## 修复 · 启动/换主题崩溃（Freezable 上下文异常）

- **崩溃现象**：应用偶发弹出「A critical error occurred…提供的 DependencyObject 不处于此 Freezable 的上下文」并退出，堆栈指向 `GlassAppearance.ApplyWindow → FluentWindow.SetWindowBackdropType`。
- **根因**：窗口加载/系统主题变化（`Loaded` 类处理器、`SystemParameters.StaticPropertyChanged`、`UserPreferenceChanged`）可能发生在 WPF 渲染回调（`CompositionTarget.Rendering`）期间；此时同步修改 WPF-UI 的 backdrop 依赖属性会触发 Freezable 上下文校验失败。
- **修复**：所有主题/backdrop 应用改为 `Dispatcher.BeginInvoke(Background)`——在当前渲染帧之后执行；`ApplyWindow` 整体 try/catch，backdrop 应用失败降级为保留原外观而非整个进程退出。

## 测试

- 充电环呼吸像素级验证（周期两端绿色通道差异）、非充电环不受脉动影响、四种托盘样式 + 脉动渲染冒烟。
- `--glass-preview` 12 张预览 + `--settings-probe` 8 语言底栏宽度 + layout probe 三档高度，CI 全绿。
