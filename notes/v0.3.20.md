# v0.3.20 · 关于窗口修正

2026-11-04。修复关于窗口的版本号、图标清晰度、中文内容和底部按钮布局。

## 修复内容

- 版本号不再写死为 0.2.0 / 1.0.0，关于窗口统一读取当前程序集版本。
- 应用图标显式选择 ICO 资源中的 256×256 帧，避免小图标放大造成模糊。
- 补齐简体中文概览、核心亮点、五项功能介绍和关闭按钮，不再回退为英文。
- 底部「检查更新 / GitHub 仓库 / 确定」改为三列布局，统一保留 12 DIP 间距。
- 八种语言的关于窗口版本格式统一，并增加本地化与高清图标回归测试。
