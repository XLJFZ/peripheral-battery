# v0.3.11 · 八种语言 + 「不保存并关闭」

## 新语言：法语 / 德语 / 西班牙语 / 意大利语 / 繁体中文

界面语言从 3 种扩展到 8 种：简体中文、繁體中文、English、Türkçe、Français、Deutsch、Español、Italiano。

- **全量翻译**：156 个词条 × 5 种新语言全部翻译（不是英文兜底的残缺包），含托盘菜单、右键阈值菜单、编解码说明、游戏回报率、更新错误码、关于页、系统通知等所有界面。
- 语言下拉按母语名显示（Français / Deutsch / …），存储值为语言无关代码（`fr` / `de` / `es` / `it` / `zht`）；`zh-hant`、`zh-tw`、`zh-hk` 均映射到繁体中文。
- 各语言同步设置对应的线程区域性（fr-FR / de-DE / es-ES / it-IT / zh-TW），日期数字格式随语言。
- 旧 `Settings_LanguageDesc` 里写死的「(English / Türkçe)」改为通用文案。

## 设置窗口：「不保存并关闭」

底栏原来是单一「保存并关闭」，现在左侧多一个**不保存并关闭**按钮——改动只对当前会话生效、不写入 settings.json（点 ✕ 关闭本来就是这个行为，现在有明确的入口）。三语与五种新语言全部提供文案。

## 测试

- 新增 `LocalizationCoverageTests`：8 种语言齐全；每种语言对 22 个跨界面代表词条均能解析（不回落 key）；`{0}`/`{1}` 占位符在翻译中保留；繁体与简体同键不同值。
- 全量单测 68 项通过。
