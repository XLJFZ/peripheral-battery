# v0.3.17 · 每设备托盘图标 + 充电呼吸环

2026-11-03。竞品功能调研候选 ①④（前两项已于 v0.3.16 发布）。

## 每设备独立托盘图标

- 新增开关（设置 → 外观 → 托盘图标区，默认关闭）：为每台有电量读数的已连接设备显示一个**独立托盘图标**——电量环 + 设备象形图（鼠标 / 键盘 / 耳机 / 耳塞 / 音箱 / 手柄 / 手表 / 手机 / 触控笔 / 通用电池，手绘矢量，不依赖图标字体）。
- 最多 4 个（电量最低的优先），避免通知区泛滥；图标左键开关浮窗、右键打开完整菜单。
- 原聚合图标保留，作为菜单与浮窗的固定入口。
- 隐藏的设备（v0.3.16）不会出现在托盘。

## 充电呼吸环

- 充电时电量环变为绿色并**呼吸闪烁**（约 1.3 秒一个正弦周期，透明度 45%↔100%），独立图标与聚合主图标均生效。
- 新增开关「充电时电量环呼吸动画」（默认开启）；关闭后独立图标回退为角标闪电。

## 其他

- 设置 → 外观新增两项开关（3 个新词条 × 8 语言）。
- 新增 PerDeviceTrayTests 5 例：图标选择规则（仅连充电量可读、最低电量优先、4 个上限）、呼吸透明度数学、全设备类型渲染冒烟、默认值。CI 过滤器全量 172/172。
