# v0.3.14 · 本地 REST API 安全加固

2026-11-03。对 v0.3.13 代码自检 review，并首次 review 此前从未审过的本地 REST API 服务，修复发现的问题。

## 本地 REST API（`http://127.0.0.1:<port>`，设置中默认关闭）

- **移除 CORS 通配符（重要）**：此前响应带 `Access-Control-Allow-Origin: *`，任何网站都能在浏览器里通过 fetch 读取本机设备清单（设备名、ID、电量、音量端点），构成静默数据外泄通道。该 API 的使用者是本地脚本与 curl，不依赖浏览器跨源读取，通配符没有正当用途。移除后浏览器侧跨源读取被拦截，本地工具不受影响。
- **/health 版本号修正**：返回的 `version` 此前硬编码 `"1.0.0"`，现在报告真实运行版本。
- **查询参数解析收紧**：`?connected=true` 过滤此前用子串匹配，`?lastconnected=true` 这类参数也会误触发过滤；现在按精确键值对解析。

## 自检修复

- 修正一个恒真的测试断言（注册表读取用例改为「null 或指向真实目录」的可证伪断言）。
- 新增 LocalRestApiTests：查询过滤的真值表（含 `?lastconnected=true` 回归用例）、端口钳制、以及真实起服的端到端用例（/health 版本正确性 + 无 CORS 头 + /devices 过滤行为；http.sys 无权限的环境自动跳过）。
