# v0.2.3 本地验证记录

本版修复附近耳机混入列表与 HID 失败时保留旧电量的问题。电量悬停提示增加原始值和采样时间；网页补上手动重新采样、过期清除、未知状态和记录导出。雷蛇电量核对见 [核对记录](2026-10-30-battery-check.md)。

Windows 本机已完成：24 项托盘相关测试、18 项 Python 后端及连接器测试、WebHID 协议测试和网页状态测试。打包程序与网页均读到本机鼠标 `230/255 → 90%`。已有依赖兼容性警告仍存在，相关测试通过不表示所有继承的蓝牙协议已经实机验证。

Mac 首版位于 [`macos/`](../macos/README.md)，本机完成 19 项跨平台逻辑测试。GitHub Actions 已分别在 Apple 芯片和 Intel 的 macOS 环境通过同一套测试、应用构建、签名校验和原生依赖导入检查，生成两套应用包；构建通过不等于蓝牙权限、真实设备、菜单栏交互和通知已完成实测，仍按预览版交付。

GitHub Pages 的发布文件已与 `web/index.html` 同步。本轮源代码已推送，网页已部署并通过浏览器验收。构建结果见 [本轮检查](https://github.com/XLJFZ/peripheral-battery/actions/runs/40932820708)，下载见 [v0.2.3](https://github.com/XLJFZ/peripheral-battery/releases/tag/v0.2.3)。
