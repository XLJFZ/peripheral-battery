# v0.3.8 · 应用内更新 + 设置页分组 + 紧凑档单行省略

三件事一起做：装上之后能在应用里点一下完成升级；设置页不再一屏拉不到底；紧凑档长设备名不再折成两行。

## 1. 应用内更新（仅安装版）

「设置 → 高级 → 软件更新」里点「检查更新」，发现新版本后原本只能跳浏览器。本版把后半段补上了：

| 步骤 | 实现 |
| --- | --- |
| 下载 | `Services/Update/UpdateInstaller.cs` 流式下载 Setup 到 `%LOCALAPPDATA%\PeripheralBattery\updates`，进度按字节回报 |
| 校验 | 拉 release 里的 `sha256.txt`，取对应文件名那一行（兼容 `<hash>  <file>` 与 `<hash> *<file>`），比对整包 SHA-256 |
| 去 MOTW | `kernel32!DeleteFile` 删除 `:Zone.Identifier` 备用流，避免升级途中弹 SmartScreen |
| 静默安装 | `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CLOSEAPPLICATIONS /FORCECLOSEAPPLICATIONS`，装完由安装包自己把托盘程序拉起来 |
| 保留自启选择 | 按当前 `LaunchAtStartup` 传 `/TASKS=autostart` 或 `/TASKS=""`，升级不会把用户取消过的开机自启又打开 |

安全边界：

- 下载与校验地址只接受 `github.com` / `objects.githubusercontent.com` / `github-releases.githubusercontent.com` 的 HTTPS，其他一律 `blockedHost`。
- **拿不到校验值就中止**（`noChecksum`），不做「先装再说」。校验不过直接删文件（`hashMismatch`）。
- 便携版 `IsInstalledCopy()` 判定为 false，提示「便携版不能自动升级，已打开下载页」并跳浏览器，不会去执行任何 EXE。

失败原因分 7 类（`blockedHost` / `noInstaller` / `noChecksum` / `hashMismatch` / `httpError` / `cancelled` / 兜底），三语各一套文案；过程日志写在 `%LOCALAPPDATA%\PeripheralBattery\update.log`，出问题可以直接看。

## 2. 设置页分组折叠

原来一列到底的 12 张卡片收进 4 组，组头是自绘 `ToggleButton`（箭头 + 标题），点击展开/收起：

| 分组 | 内容 | 默认 |
| --- | --- | --- |
| 外观 | 界面外观、面板大小、托盘图标与颜色 | 展开 |
| 行为 | 阈值、刷新间隔、游戏回报率调度、登录自启 | 展开 |
| 通知 | 低电量提醒、提醒方式 | 收起 |
| 高级 | REST API 端口、软件更新 | 收起 |

发现新版本时自动把「高级」组展开，避免「下载并安装」按钮被折叠藏起来。

## 3. 紧凑档设备名单行省略

紧凑档（344 宽）里 `Razer DeathAdder V3 Pro (Wireless)` 这类长名字会折成两行，把卡片撑高、破坏列对齐。现在按档位切换：

- 紧凑档：`TextWrapping=NoWrap` + `TextTrimming=CharacterEllipsis`，单行截断，完整名称仍在 `ToolTip` 里。
- 标准 / 宽松档：保持换行显示。

两个值走 `FlyoutNameWrapping` / `FlyoutNameTrimming` 动态资源，切档位即时生效，不用重开面板。

## 已知项

- 应用内更新仅支持安装版；便携版仍为「下载新 EXE 覆盖」。
- 静默安装期间窗口会闪一下（安装包自己拉起的进程），属预期。
