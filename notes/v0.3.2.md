# v0.3.2 · 液态玻璃与普通版

外观设置现在只提供两个选项：**液态玻璃**和**普通版**。默认使用普通版，已有深色、浅色或跟随系统配置在设置页统一显示为普通版；旧液态玻璃配置统一显示为液态玻璃。选定后点击“保存并关闭”生效。

液态玻璃改用中性浅色、系统 Acrylic 背景、柔和高光和透明内容层，去掉上一版的蓝色染色、卡片亮边叠加和悬停放大。电量数字使用深色，进度条保留电量颜色。普通版保留原有深色界面。切换时同时刷新已打开窗口的主题资源，修复切回普通版后设置页出现浅色背景与白字混用的问题。

Windows 关闭透明效果或启用高对比度时，玻璃效果会退化为便于阅读的表面。实际背景模糊取决于 Windows 版本和系统设置，本版没有实现 Apple 的光学折射效果。

本次公开发布也包含此前的本地更新：设备拖拽排序、雷蛇原生电量读取、读取失败状态区分，以及设置和关于窗口中的 GitHub 仓库按钮。雷蛇改为直接读取硬件电量，不再优先采用雷云本地日志，数字可能与雷云界面不同。其他品牌继续使用原有后端。

游戏回报率调度默认关闭，仅对已验证的炼狱蝰蛇 V3 Pro `1532:00B7` 接收器开放 125–1000Hz；退出或关闭时尝试恢复原回报率，异常退出后保留恢复记录供下次启动重试。此前实机已验证 1000Hz → 500Hz → 1000Hz 的切换及回读。4000/8000Hz 尚未开放，真实游戏中的自动触发仍未完成实测。

QK75N 目前只识别设备，USB 电量协议尚未适配。未知或读取失败的电量不显示成 0%。

## 使用

完整解压 Windows 压缩包，保留全部文件，双击 `启动托盘版.cmd`。外观设置中选择“液态玻璃”或“普通版”；游戏回报率调度入口位于设置窗口底部。

## 验证

- 24 项相关原生测试、37 项 Python 测试通过。
- 两种外观的面板、设置页均完成渲染检查，并检查运行中资源切换与两个外观选项。
- 发布包菜单、提示框及游戏调度窗口检查通过。实际桌面自动化捕获未能稳定完成，因此不把离屏渲染检查描述为完整的桌面材质验收。
- 预览图片使用示例设备与电量，未包含本机设备路径、序列号、日志或连接令牌。

设计参考：[Apple Liquid Glass 讲解](https://developer.apple.com/videos/play/wwdc2025/219/)、[Microsoft Acrylic 指南](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)。本项目使用 Windows 原生背景材质与独立编写的界面代码。
